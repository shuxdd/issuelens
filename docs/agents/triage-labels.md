# 分诊标签

相关技能使用五种标准分诊角色。下表将这些角色映射到本仓库问题跟踪器中的实际标签字符串。

| mattpocock/skills 中的标签 | 本仓库中的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估该问题 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格已完整，可交给自主代理处理 |
| `ready-for-human` | `ready-for-human` | 需要由人类实现 |
| `wontfix` | `wontfix` | 不会处理 |

当技能提到某个角色时，使用本表对应的标签字符串。

如需适配仓库现有的标签术语，可直接修改右侧“本仓库中的标签”列。
