# 12: 运行 G1–G4 可比较实验与人工评审

**What to build:** 在同一冻结数据和模型配置上运行四组系统，生成可复现的检索、根因、引用、稳定性、成本和延迟报告，并支持项目作者与第二位评审者进行盲评。

**Blocked by:** 09: 实现受控预算与四类调查终态；10: 让每次调查可追踪、可计算成本；11: 扩充并冻结正式评测数据集

**Status:** ready-for-agent

- [ ] G1 为向量检索加固定单轮生成器，G2 为混合检索加同一生成器，G3 增加 Reranker，G4 使用 G3 检索与完整 Agent。
- [ ] 四组实验固定数据版本、模型、提示词适用范围、报告 Schema 和评测器版本。
- [ ] 报告分别计算三类文件 Recall、MRR、nDCG、根因正确率和宏平均引用有效率。
- [ ] 30 条主评测案例各运行一次，10 条稳定性子集各保留三次独立运行。
- [ ] 项目作者完成 30 条盲评，第二位评审者完成固定 10 条子集并记录一致率、分歧和仲裁。
- [ ] LLM Judge 结果只作为辅助列展示，不替代人工和确定性指标。
- [ ] 报告公开逐案例结果、聚合结果、Token、费用、延迟和未达标指标。
- [ ] 完整 Agent 的增益按规格中的预注册阈值判断，而不是事后重新定义。
