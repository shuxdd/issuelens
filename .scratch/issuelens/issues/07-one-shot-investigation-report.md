# 07: 从检索结果生成可引用的单轮调查报告

**What to build:** 让贡献者获得第一份英文结构化调查报告。G1、G2 和 G3 使用完全相同的单轮报告生成器，使不同检索方案可以在根因、引用和成本上公平比较。

**Blocked by:** 04: 用向量检索定位第一个根因文件

**Status:** ready-for-agent

- [ ] 报告包含问题分类、事实、最多三个根因假设、证据、置信度和未解决问题。
- [ ] 报告符合稳定 Schema，结构化输出无效时返回可诊断错误。
- [ ] 每条事实或根因结论引用调查时点内的 commit、路径和行号，或标记为未验证假设。
- [ ] G1、G2 和 G3 共用同一提示词、模型配置和报告生成逻辑。
- [ ] 报告生成记录 Token、费用、延迟、模型和提示词版本。
- [ ] 固定响应测试能覆盖有效报告、无效引用和结构化输出失败。
