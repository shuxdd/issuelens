# 03: 构建 10 条无泄漏 Starlette 调查案例

**What to build:** 从真实 GitHub 公开数据生成首批 10 条可人工审查的 Starlette 调查案例，可靠恢复 Issue 与 closing PR 的关系，记录筛选漏斗，并阻止调查时点之后的信息进入允许证据。

**Blocked by:** 02: 导入并审查一个固定调查案例

**Status:** ready-for-agent

- [ ] 数据采集能够缓存 Issue、timeline、交叉引用、PR、提交和文件变更元数据。
- [ ] Issue–PR 关系通过 timeline 或交叉引用恢复，而不只依赖正文正则。
- [ ] 构建结果包含 10 条人工复核通过的调查案例。
- [ ] 每条案例都有可追溯来源、调查时点、快照 commit 和测试变更引用。
- [ ] 安全漏洞、纯文档、依赖机器人、跨仓根因和不可分析案例被排除并记录原因。
- [ ] 人工注入未来证据时，泄漏检查返回失败。
- [ ] 重复采集使用缓存并保持幂等，且能输出各筛选阶段的数量。
