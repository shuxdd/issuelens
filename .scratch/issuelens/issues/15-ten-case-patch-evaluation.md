# 15: 扩展到 10 条补丁案例并计算指标

**What to build:** 将单案例补丁验证扩展到 10 条可稳定复现的调查案例，允许每条最多两次候选补丁，并报告复现、应用、测试、回归、成本和耗时结果。

**Blocked by:** 11: 扩充并冻结正式评测数据集；14: 在一个案例中贯通补丁验证沙箱

**Status:** ready-for-agent

- [ ] 10 条案例均固定修复前 commit、兼容 Python 版本、基础环境和目标失败测试。
- [ ] 每条案例最多执行两次补丁尝试并保留每次 diff 与测试结果。
- [ ] 替代补丁通过相同行为测试且无相关回归时可判定成功。
- [ ] 报告包含 Reproduction Rate、Patch Apply Rate、Target Test Pass Rate、Regression-free Rate、Pass@1 和 Pass@2。
- [ ] 每条案例均报告运行时间、工具调用、Token、费用和终止原因。
- [ ] 无法重建的冻结案例不会被静默移除，必须以运行失败保留在分母中。
- [ ] 补丁成功率不足 50% 时，生成的项目表述不会声称自动修复成功。
