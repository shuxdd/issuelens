# 10: 让每次调查可追踪、可计算成本

**What to build:** 让项目作者和贡献者能够追踪一次调查经历的状态、检索、工具、模型调用、Token、费用、延迟和停止原因，并能在 Langfuse 不可用时保留本地记录。

**Blocked by:** 08: 贯通完整 Agent 的 supported 调查路径

**Status:** ready-for-agent

- [ ] 每次调查产生有顺序、可关联的本地结构化事件。
- [ ] 事件覆盖状态转换、检索候选、工具参数摘要、模型调用、耗时、Token、费用和终态。
- [ ] Langfuse 能显示同一调查的节点、工具和模型调用层级。
- [ ] 评测分数可以关联到相应调查轨迹和实验运行。
- [ ] 关闭 Langfuse 后，调查和离线评测仍能完成。
- [ ] 上传观测数据前排除 API 密钥、环境变量和不必要的容器原始输出。
- [ ] 固定测试能验证异步调查不会丢失父子事件关系。
