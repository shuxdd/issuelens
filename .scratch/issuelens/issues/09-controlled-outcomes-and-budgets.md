# 09: 实现受控预算与四类调查终态

**What to build:** 让调查系统在证据不足、工具失败、预算耗尽或危险请求下给出明确且可操作的终态，而不是无限循环或笼统失败；交互模式还能提出有限的澄清问题。

**Blocked by:** 08: 贯通完整 Agent 的 supported 调查路径

**Status:** ready-for-agent

- [ ] `supported`、`insufficient_evidence`、`budget_exhausted` 和 `unsafe_request` 均可由固定案例触发。
- [ ] 每种终态都包含停止原因、已收集证据和未解决问题。
- [ ] 交互模式最多输出三个具体澄清问题。
- [ ] 评测模式不接受运行中补充信息，证据不足时安全终止。
- [ ] 总工具调用、检索改写、根因假设、补丁尝试和运行时间均受预算限制。
- [ ] 达到预算后不再调用工具，结构化输出失败只执行有限恢复。
- [ ] 不使用笼统 `failed` 代替领域终态。
