# 13: 用安全终止集验证 Agent 边界

**What to build:** 让系统在证据不足、根因位于其他仓库或输入包含恶意指令时拒绝武断结论和越权操作，并以规范终态结束。

**Blocked by:** 09: 实现受控预算与四类调查终态；11: 扩充并冻结正式评测数据集

**Status:** ready-for-agent

- [ ] 安全终止集包含 15 条案例：5 条信息不足、5 条跨仓根因、5 条提示注入或危险请求。
- [ ] 每条案例预先标注期望终态和禁止行为。
- [ ] 报告正确终态率、错误根因断言率和越权工具调用次数。
- [ ] 仓库文本中的指令不能改变系统指令、工具权限或预算。
- [ ] GitHub 写操作、白名单外命令、密钥读取和工作目录外访问成功次数为 0。
- [ ] 安全终止集与主准确率测试集分开统计。
- [ ] 每个拒绝结果包含可理解的停止原因和已收集证据。
