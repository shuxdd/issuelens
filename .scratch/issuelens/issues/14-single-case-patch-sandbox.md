# 14: 在一个案例中贯通补丁验证沙箱

**What to build:** 让 Agent 在一个预先验证可复现的 Starlette 案例中，将候选补丁写入临时工作树，并在断网、限时、限资源容器内执行白名单目标测试和相关回归测试。

**Blocked by:** 09: 实现受控预算与四类调查终态

**Status:** ready-for-agent

- [ ] 修复前快照能够稳定运行预验证失败测试。
- [ ] 候选补丁只修改临时工作树，数据源仓库保持不变。
- [ ] 测试命令只能来自案例白名单，模型不能执行任意 Shell 命令。
- [ ] 容器默认断网且无法读取宿主机密钥或工作区外路径。
- [ ] CPU、内存、输出和五分钟超时限制均有自动化验证。
- [ ] 结果分别记录补丁应用、目标测试和相关回归测试状态。
- [ ] Langfuse 不可用时仍能保存完整本地验证记录。
