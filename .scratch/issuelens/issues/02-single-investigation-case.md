# 02: 导入并审查一个固定调查案例

**What to build:** 让项目作者能够从固定的 GitHub 响应和 Starlette 仓库快照生成一个版本化调查案例，并通过 CLI 或 API 审查 Issue、调查时点、允许证据、修复证据和来源信息。

**Blocked by:** 01: 建立可运行的 IssueLens 纵向骨架

**Status:** ready-for-agent

- [ ] 固定输入可以生成一个符合版本化 Schema 的调查案例。
- [ ] 案例包含 Issue 标识、调查时点、快照 commit、允许证据和修复证据引用。
- [ ] 允许证据与修复证据在序列化结果中具有不同字段和读取权限。
- [ ] CLI 或 API 能显示案例来源、时间边界和当前校验状态。
- [ ] 同一固定输入连续构建两次产生等价结果，不重复创建逻辑案例。
- [ ] 无网络、无模型 API 和无 Langfuse 时测试仍可运行。
