# 16: 交付五条调查轨迹的受控 Web Demo

**What to build:** 提供一个英文 Web Demo，让访问者选择五条预置 Starlette 案例，查看调查状态、轨迹时间线、英文报告、证据侧栏和补丁验证结果，同时阻止任意代码与命令输入。

**Blocked by:** 10: 让每次调查可追踪、可计算成本；12: 运行 G1–G4 可比较实验与人工评审；13: 用安全终止集验证 Agent 边界；15: 扩展到 10 条补丁案例并计算指标

**Status:** ready-for-agent

- [ ] Demo 固定展示 2 条 `supported`、1 条 `insufficient_evidence`、1 条 `budget_exhausted` 和 1 条 `unsafe_request`。
- [ ] 至少一条 `supported` 案例展示候选补丁和测试验证结果。
- [ ] 用户能够从报告结论跳转到相应 commit、路径、行号和证据内容。
- [ ] 默认回放预生成轨迹，不在公开环境实时执行补丁测试。
- [ ] API 只接受白名单案例 ID，不接受仓库 URL、代码、补丁或命令。
- [ ] IP 级速率限制、全局并发限制和 HTTP 429 行为可验证。
- [ ] SSE 不可用时页面能够使用轮询恢复进度或轨迹加载。
- [ ] 服务错误和无效案例显示可操作的英文错误信息。
